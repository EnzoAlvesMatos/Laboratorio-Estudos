O Que e o Site

Eu criei este projeto com o objetivo de aprender como funciona a linguagem C, já que é a primeira vez que estou utilizando essa linguagem. A seguir, vou mostrar os exercícios realizados.

Como instalar

Para utilizar este projeto, é necessário ter o auxílio de uma IDE, como, por exemplo, o Visual Studio Code, ou um compilador online, como o myCompiler. Também é necessário ter um ambiente de execução compatível com a versão GCC-6.3.0-1.
